# Claude Code memory backup

A copy of the persistent memory Claude Code keeps for this project (normally
stored outside the repo, on the codespace's own disk, which is wiped on
rebuild/delete). Backed up here so a codespace loss doesn't erase it.

Refreshed occasionally, not on every change. `MEMORY.md` is the index; the
other files are the individual entries it links to.

**Redacted before committing** (this repo is public, this branch included):
specific pricing figures, a GCP service-account email, a GCP project name,
GA4 measurement IDs, and Apple Developer Team ID / App Store Connect Apple
ID / bundle ID. Everything else is kept as originally written.
